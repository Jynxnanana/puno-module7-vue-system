# Add Active/Archived Order Filter — Perfective Maintenance

| **Field** | **Content** |
|---|---|
| **Title / Type** | Add Active/Archived Order Filter — Perfective Maintenance |
| **Problem / Opportunity** | Completed orders accumulate in the main list, making it harder for staff to scan currently active (Pending/Preparing) orders. There is no way to hide finished orders without deleting them. |
| **Desired Outcome** | Staff can filter the order list to show only **Active** orders, only **Archived** orders, or **All** orders. Completed orders can be archived without being deleted. |
| **Acceptance Criteria** | 1. A filter control (**All / Active / Archived**) appears above the order list.<br>2. Selecting **Active** hides archived orders; selecting **Archived** shows only archived orders.<br>3. A new **Archive** action appears on orders with status **Completed** and sets `archived: true`.<br>4. Existing orders saved before this change (without an `archived` field) are treated as **Active** by default.<br>5. CRUD, search, validation, and persistence continue to work unchanged. |
| **Priority / Rationale** | **Low risk, high usability value.** The change is isolated to the list/filter layer and does not affect order creation or validation logic. |
| **Affected Areas** | `src/utils/orderUtils.js` (new `filterByArchiveState` helper + localStorage normalization), order list component (UI + state), tests, README, CI. |

## Summary

This perfective maintenance enhancement improves the usability of the Food Ordering System by allowing staff to organize completed orders without permanently deleting them. Orders can now be filtered by **All**, **Active**, or **Archived** status while preserving existing CRUD, search, validation, and localStorage functionality.=
